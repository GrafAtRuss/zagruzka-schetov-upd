Загрузка счетов и УПД из PDF
Расширение для 1С:Бухгалтерия предприятия 3.0, платформа 8.3.21 и новее, Windows.

Что делает
- В левом меню появляется раздел «Загрузка PDF».
- Внутри него обработка «Загрузка счетов и УПД».
- Роль «Загрузка счетов и УПД из PDF» (ЗС_ЗагрузкаСчетовИзPDF).
  Без этой роли раздел скрыт. Роль не выдается всем автоматически: ее назначает администратор.
- Из PDF счета покупателю или УПД создаются:
  1. Счет на оплату покупателю
  2. УПД статуса 1: реализация услуг и счет-фактура выданный
- Контрагент ищется по ИНН, если его нет — создается. Договор ищется по наименованию основания.
- Организация ищется по ИНН поставщика из файла.
- НДС 5% и другие ставки берутся из перечисления СтавкиНДС, сумма считается «в том числе».

Как подключить
1. Распакуйте архив.
2. Конфигуратор — Конфигурация — Расширения конфигурации — Создать.
3. Конфигурация — Загрузить конфигурацию из файлов — укажите папку ЗагрузкаСчетовУПД.
4. Если платформа ругается на язык «Русский»: в расширении откройте язык Русский и в поле «Объект расширяемой конфигурации» выберите Русский вашей бухгалтерии. Либо в проверке применимости нажмите «Исправить».
5. Снимите флажок «Безопасный режим». Иначе обработка не сможет запустить PowerShell и прочитать текст PDF.
6. У пользователей, которые будут загружать файлы, снимите «Защита от опасных действий» либо разрешите расширение.
7. Администрирование — Настройки пользователей — нужным пользователям добавьте роль «Загрузка счетов и УПД из PDF».
8. Обновите базу и откройте предприятие. Слева будет раздел «Загрузка PDF».

Ограничение
Текст из PDF читается на Windows через PowerShell. Файл должен быть с текстовым слоем, как печатная форма 1С, а не фотография скана.
