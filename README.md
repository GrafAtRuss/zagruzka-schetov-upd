Загрузка счетов и УПД из PDF
Расширение для 1С:Бухгалтерия предприятия 3.0, платформа 8.3.21 и новее, Windows.
Версия 1.0.2

Каталог выгрузки — это папка, прямо в которой лежат Configuration.xml и ConfigDumpInfo.xml.
Архив zip и папка уровнем выше конфигуратором не принимаются: «Источник XML выгрузки не является каталогом».

Установка: распакуйте архив и запустите InstallExtension.bat из папки, где лежит Configuration.xml.

Что делает
- В панели разделов появляется «Загрузка PDF».
- Внутри него обработка «Загрузка счетов и УПД».
- Роль «Загрузка счетов и УПД из PDF» (ЗС_ЗагрузкаСчетовИзPDF).
  Без этой роли раздел скрыт. Роль не выдается всем автоматически.
- Из PDF счета покупателю или УПД создаются:
  1. Счет на оплату покупателю
  2. УПД статуса 1: реализация услуг и счет-фактура выданный
- Контрагент ищется по ИНН, если его нет — создается.
- Организация ищется по ИНН поставщика из файла.
- НДС берется из файла, сумма считается «в том числе».

После установки скриптом
1. Снимите у расширения «Безопасный режим» и «Защита от опасных действий».
   Иначе обработка не сможет запустить PowerShell и прочитать текст PDF.
2. Назначьте роль нужным пользователям.
3. Обновите сеанс. Слева будет раздел «Загрузка PDF».

Ограничение
Текст из PDF читается на Windows через PowerShell. Файл должен быть с текстовым слоем, как печатная форма 1С, а не фотография скана.
