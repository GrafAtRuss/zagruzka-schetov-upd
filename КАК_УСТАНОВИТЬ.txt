Если конфигуратор пишет «Источник XML выгрузки не является каталогом»
--------------------------------------------------------------------
Выбран не каталог выгрузки. Нужна папка, прямо в которой лежат
Configuration.xml и ConfigDumpInfo.xml.
Не выбирайте zip, не выбирайте папку уровнем выше и не выбирайте сам файл xml.
Проще запустить InstallExtension.bat из этой же папки.

Расширение «Загрузка счетов и УПД из PDF» для 1С:Бухгалтерия предприятия 3.0
Версия 1.0.22
Платформа 8.3.21 и новее, Windows
=============================================

Это расширение конфигурации, не внешняя обработка.
После установки у пользователей с ролью «Загрузка счетов и УПД из PDF»
в панели разделов появляется «Загрузка PDF».
Внутри раздела команда «Загрузка счетов и УПД».

Установка
---------
1. Распакуйте архив целиком.
2. Запустите InstallExtension.bat двойным щелчком из этой папки.
   Не пересохраняйте bat в UTF-8: cmd тогда ломает команду powershell.
3. Скрипт спросит платформу, файловую или серверную базу, пользователя.
   Для сервера укажите имя кластера и имя базы, как в окне запуска 1С.
   Порт пустой — это 1541. Вход Windows — отдельный пункт.
4. Скрипт загрузит расширение, обновит его в базе и сохранит
   ЗагрузкаСчетовУПД_1.0.22.cfe рядом с собой.
5. В конфигураторе откройте список расширений и у «Загрузка счетов и УПД из PDF»:
   - снимите «Безопасный режим»;
   - снимите «Защита от опасных действий» (иначе PowerShell не прочитает PDF).
6. Администрирование — Настройки пользователей и прав: нужным пользователям
   добавьте роль «Загрузка счетов и УПД из PDF».
   Роль не выдается всем сама. Без нее раздела нет.
7. Перезапустите сеанс 1С.

Если раздела нет в панели
-------------------------
Откройте меню панели разделов и «Настройка панели разделов».
Включите «Загрузка PDF». Так бывает, если панель уже была настроена вручную.

Другая база
-----------
Конфигуратор, Конфигурация, Расширения конфигурации, Загрузить из файла,
укажите ЗагрузкаСчетовУПД_1.0.22.cfe, затем обновите конфигурацию базы данных.
Снимите безопасный режим и назначьте роль, как в шагах 5–6.

Если загрузка ругается на язык Русский
---------------------------------------
В дереве расширения откройте язык Русский. В поле «Объект расширяемой
конфигурации» нажмите F4 и выберите Русский. Обновите конфигурацию базы.

Что делает расширение
---------------------
Из PDF печатной формы счета покупателю или УПД создает:
1. Счет на оплату покупателю.
2. УПД статуса 1: реализация услуг и счет-фактура выданный.
Контрагент ищется по ИНН, если его нет — создается.
Организация ищется по ИНН поставщика из файла.
НДС берется из файла, сумма считается «в том числе».
Текст читается только из PDF с текстовым слоем, не из скана-картинки.
Нужен Windows: разбор PDF идет через PowerShell на этом компьютере.
